# Current design direction — 24 September 2026

The owner's latest instruction overrides the older overview's dark dashboard concept.

- Minimal, professional light theme.
- Warm white/off-white surfaces, charcoal text, thin neutral separators.
- Muted green only for primary actions and connection emphasis.
- Times New Roman for text, using a licensed supplied font; system serif fallback until supplied.
- Brief opacity feedback on buttons and section changes, respecting reduced motion.
- No neon gauges, glass effects, excessive gradients, marketing slogans, or decorative dashboard clutter.

The React Native UI has been implemented in code. Visual appearance on the physical Android device has not been inspected in this environment.
